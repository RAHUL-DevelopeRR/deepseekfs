# Brag Plan: NeuCockpit

## What is this app?
NeuCockpit is a desktop app for local file search, document summaries, and answers using an on-device model.

## The angle
The answer is already on your machine. Show a familiar search action becoming a useful file result, then a local AI summary. Keep the promise concrete and private.

## Hook (first 2.5 seconds)
Large type: “Your files know the answer.” A thin cyan cursor appears; the line holds long enough to read.

## Key moments
- A NeuCockpit-style dark search panel appears, based on the product's real search interface.
- A fictional, clearly labeled example query finds three plausible local files by meaning.
- A local summary card appears beside the selected file. The interface is an illustrative recreation, not a recorded model output.

## Outro
“Search. Summarize. Stay offline.” followed by NeuCockpit and zero-x.live.

## User flow worth showing
Open search → type a query → choose a result → request a local summary.

## Tone
- Preset: app-store
- Creative direction: fast premium desktop launch, restrained cyan and violet accents
- Interpretation: decisive cuts and fluid UI movement, with readable type and one idea per beat.

## Format: landscape — 1920x1080
## Duration: 20 seconds

## Visual identity
- Background: `#0A0A0C`
- Accent: `#00E5FF`, with `#7C4DFF` secondary
- Text: `#E8E8EC`
- Display font: Cabinet Grotesk, falling back to Arial
- Body font: Satoshi, falling back to Arial
- Strongest visual: the dark NeuCockpit search interface with category tabs and result rows

## Share copy (draft)
Your files know the answer. NeuCockpit helps you search and summarize them locally. Explore at zero-x.live.

## Audio direction
- Role: upbeat, polished bed with sparse interaction accents
- Music: bundled “Happy Beats / Business Moves” track, lightly reduced under interface moments
- Music treatment: start immediately, lift at the search results, fade through the final logo
- Music cue guidance: beat timing may be detected during composition; readability takes priority
- Audio-reactive treatment: subtle cyan edge glow may breathe with the music
- SFX posture: sparse keyboard and selection ticks
- Audio-coupled moments: query typing, result selection, final logo
- Restraint rule: no strobing or rapid unreadable text

## Storyboard

### Scene 1 — The hook — 2.5s
“Your files know the answer.” on near-black with a cyan cursor. Hold the full line.
Sequential/interaction: cursor appears after the headline.
Audio intent: one clean opening accent; music begins.
Transition mood: clean → Scene 2.

### Scene 2 — Product reveal — 3.5s
NeuCockpit name and dark search panel enter. The panel recreates the actual category tabs and search field.
Sequential/interaction: panel scales into place; cursor focuses the search field.
Audio intent: restrained rise.
Transition mood: clean → Scene 3.

### Scene 3 — Search in use — 6s
Example query “quarterly proposal” types into the search bar. Three fictional result rows appear one by one, then hold. Small “Illustrative demo” label stays visible.
Sequential/interaction: typing and result reveal.
Audio intent: quiet key taps and one result cue.
Transition mood: clean → Scene 4.

### Scene 4 — Local summary — 4.5s
The first result is selected. A local summary card opens, with short illustrative text and a visible “On-device” label.
Sequential/interaction: select row, card slides in.
Audio intent: warm soft impact, music continues.
Transition mood: clean → Scene 5.

### Scene 5 — Close — 3.5s
“Search. Summarize. Stay offline.” then NeuCockpit and zero-x.live. Hold logo and URL.
Sequential/interaction: three verbs arrive in sequence, then settle.
Audio intent: final accent and fade.

**Music mood for this video:** polished and rhythmic.
**Audio summary:** a light beat supports a real product flow; interaction sounds punctuate search, selection, and close.
